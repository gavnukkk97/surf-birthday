# 🏄 Surf Birthday Route

Интерактивный планировщик маршрута на день рождения: обойти максимум кофеен
**Surf Coffee** в Москве и собрать все бесплатные именинные напитки.

## Что умеет

- 🗺 Карта Москвы (Leaflet + OpenStreetMap) со всеми **142 точками** Surf Coffee
- 🎂 Выбор старта: поиск по адресу (Nominatim), клик по карте, перетаскивание маркера или геолокация
- 🚶🚗 Режимы «пешком» и «на машине» — время в пути по реальным дорогам (OSRM)
- 🧮 Оптимизатор: максимизирует число посещённых кофеен с учётом
  времени в пути, часов работы и паузы на каждый напиток (orienteering problem:
  мультистарт-жадный + вставка + 2-opt/or-opt)
- 📋 Таймлайн с временем прихода/ухода и ожиданиями, статистика дня
- 🧭 Экспорт готового маршрута в Яндекс.Карты + **QR-код**: наведи камеру
  телефона — маршрут откроется в Яндекс.Картах на телефоне, иди и следуй ему
- 🔗 Шаринг ссылкой (старт и настройки в URL)

## Запуск

Никакой сборки не нужно — статика:

```bash
cd surf-birthday
python3 server.py 8791
# открыть http://localhost:8791
```

`server.py` — обычный статический сервер, но с `Cache-Control: no-store`,
чтобы браузер всегда брал свежую версию кода (после правок не нужен жёсткий F5).
Подойдёт и `python3 -m http.server 8791`, но тогда при обновлении файлов
делай жёсткую перезагрузку (Cmd+Shift+R).

Можно и просто открыть `index.html` двойным кликом — но с локальным сервером
надёжнее (fetch внешних API из file:// иногда режется браузером).

## Файлы

| Файл | Что это |
|---|---|
| `index.html` / `style.css` | разметка и стили |
| `app.js` | вся логика: карта, поиск, оптимизатор, отрисовка |
| `data.js` | 142 точки сети: название, адрес, координаты |
| `tools/geocode.py` | первый проход геокодинга адресов (Nominatim) |
| `tools/geocode_fix.py` | второй проход для сложных адресов |
| `tools/make_data.py` | ручные фиксы + сборка `data.js` |

## Данные и честность

- Список спотов и адресов — с [surfcoffee.ru](https://www.surfcoffee.ru/surf-coffee-stores) (октябрь 2026).
- Координаты — Nominatim/OpenStreetMap; для трёх точек (TAKEOFF, SWALLOW, SALARIS) —
  ручные фиксы по веб-поиску, для четырёх — координата улицы, а не дома.
- Часы работы задаются глобально (по умолчанию 08:00–23:00, как у большинства
  спотов сети); у конкретной кофейни уточняйте на месте.
- Условия акции (бесплатный напиток в день рождения) — по программе лояльности
  Surf, детали уточняйте в их приложении/у бариста.
- Время «на машине» — без учёта пробок (OSRM).

Проект не связан с Surf Coffee — это фанатский планировщик дня рождения 💛

## Технические детали

- Подложка карты: три бесплатных провайдера тайлов с автофолбэком
  (CARTO → Esri Light Gray → OSM): битые тайлы перезагружаются автоматически,
  при массовых ошибках подложка переключается сама; кнопка 🗺 справа на карте
  переключает её вручную.
- Матрица времени: OSRM `/table` (пешком — FOSSGIS `routed-foot`, авто —
  demo-сервер `router.project-osrm.org`). Берутся ~90 ближайших к старту точек
  (лимит сервера — 100 координат). Если серверы недоступны — офлайн-фолбэк:
  оценка по прямой с поправкой 1.32 на планировку улиц.
- Геометрия маршрута: OSRM `/route` с `overview=full`; фолбэк — прямые segmentы.
- Оптимизация: 10 мультистартов (жадный по раннему прибынию → жадная вставка
  непосещённых → 2-opt + or-opt по времени финиша). Выбирается вариант с
  максимумом кофеен, при равенстве — с самым ранним финишем.
